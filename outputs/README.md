## 开始体验

- 找适合我的职位：左侧对话逐项呈现用户画像、推荐方向与站内检索记录，右侧保留原简历，完成后打开校招项目建议与相关职位；不计算匹配分。
- 针对职位改简历：大舞台左侧职位 JD 与右侧同一张真实 A4 联动。对话与要求可在抽屉查看；先分析、完成四页选择并在最后一页确认，再逐条改写普通正文。不会用另一个结果副本替换可编辑的纸面。
- 批量筛选职位：承接粗筛池 → 细化城市、方向、类型、薪资、行业、匹配度要求 → 逐岗精筛，仅列出达标岗位和分数 → 双材料准备 → 确认模拟投递 → 我的职位看板。默认最低匹配度80；结果比粗筛少，调整要求仍从完整原池重筛。
- 填写网申：按三组填写10个字段，已有信息逐项进入，手机号和到岗时间由用户补充；核对完成只记录待提交，不发送外部表单。

侧栏「发现职位」和「我的职位」支持筛选、搜索、详情、加入待投、列表/看板及状态变更，与 Agent 共享同一份按职位 ID 保存的本地状态。看板显示「已投递 / HR 已读 / 面试 / 结果」四列，支持跨列调整和迁移动画；进入面试状态后可展开准备入口，状态不会凭空自动生成。

模拟面试分为准备、八题文字问答、报告三个阶段。问题围绕当前职位与示例经历，每题至少输入10字后继续；报告保留原回答、五维表达检查、逐题回顾和练习计划。波形用于演示视觉，没有麦克风或音频识别；检查分依据明确的本地文字规则，不是真实模型评价，也不预测录用结果。

新建对话恢复示例简历和当前会话，不清除本地职位进度。关闭预览不会停止执行；停止或新任务会清理旧工作流计时器。执行中仍能排队输入、立即引导或删除排队消息。各阶段使用本地模拟时序，不能将演示等待时间等同于真实服务性能；「功能验证」内可推进下一步。

## 分析与修改

分析先从通读简历、理解岗位目标开始：前3.6秒左侧显示分析进度，右侧不高亮、不自动定位。确定分析重点后才定位项目标题，5.4秒进入结构核对，7.2秒显示结论，到9秒开始逐条阅读。后续需求、职责、结果三条原文仍按阅读→2.4秒核对→6.5秒结论→9秒下一条推进。左侧沿用 Thought 与执行状态文字，右侧采用官网的蓝色虚线呼吸高亮；正文保持原样，不显示「已修改」。分析完成或停止后清除执行高亮。

确认建议或明确要求改写后，才实际修改正文。进入编辑的定位准备阶段先高亮整个「项目经历」模块；实际开始改写后，每次只高亮当前正在修改的一条，下一条开始时高亮随之移动，不再叠加整个模块的高亮。每条写完、等待下一步时保持当前条定位；精简成单条后定位到保留的正文。写入过程使用正常正文样式，不显示红色删除线、绿色新增文字或修订标记。完整写完后才显示完成回执；原文已符合目标则提示无需修改。系统开启「减少动态效果」时直接提交目标段落。

逐字时序是用户要求的功能验证行为，不代表官网已有同样的打字动画。2026-10-28 上一版取消红/绿修订标记并采用整轮模块高亮；本次按进一步明确的要求，将实际改写阶段改为每条独立高亮，普通正文保留。重读官网 renderer 后继续复用原蓝色虚线呼吸样式，仅改变高亮目标。它没有独立的对话内动画画布，也没有先前自建的闪烁输入光标或滑动蓝色条。

自动步骤到时若仍在写入，会等待写完。停止立即取消写入、保留当前文字并清除编辑高亮；完成整轮后也清除编辑高亮。旧回调不能覆盖新任务。继续引导时保持当前轮次、步骤和主计时，必要时从已显示的文字重新调整目标。

## 不中断引导

执行时输入框为空，原位置显示灰色停止按钮；输入文字后变为蓝色发送箭头。发送后进入输入框上方的待发送副栏。

- 折向上的箭头：立即引导当前任务，不重启步骤或计时。
- 垃圾箱：删除待发送消息；卡片来源会恢复整组卡片编辑状态。
- 不点击折箭头：当前轮次完成后按顺序自动发送。

支持连续补充，保留主输入框独立草稿。停止后普通待发送消息恢复为草稿，卡片恢复选择和自定义输入。分析任务收到补充仍只分析，不会提前修改正文。

同场景补充可立即引导，另一个场景的请求会排队到本轮结束，折箭头暂时禁用。停止后排队场景保留「继续此任务」入口。筛选条件支持有限规则解析；未能对应具体条件的补充会保留为待确认，不当作已完成的语义执行。
